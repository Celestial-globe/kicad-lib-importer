KiCad Library Importer

部品サイトからダウンロードした KiCad ライブラリの ZIP をドロップするだけで、指定フォルダへ保存し、シンボル・フットプリント・3D モデルのリンクと sym-lib-table / fp-lib-table を一括設定します。処理はすべてブラウザ内で完結し、ファイルが外部に送信されることはありません。

このブラウザは File System Access API に対応していないため、フォルダへの直接保存ができません。Google Chrome または Microsoft Edge（PC 版）で開いてください。

1ライブラリの保存先

ローカルフォルダのほか、ネットワークドライブ（例: Z:\KiCadLib）も選択できます。選択したフォルダは次回以降も記憶されます。
「KiCad から見たパス」はブラウザが絶対パスを取得できないために必要です。KiCad の「設定 → パスを設定」で環境変数（例: MY_KICAD_LIB）を登録して ${MY_KICAD_LIB} と書くと、PC ごとにドライブ文字が違っても使えます。プロジェクト登録で保存先がプロジェクト内にある場合は自動で ${KIPRJMOD} 相対になります。

2ライブラリテーブルの登録先

未選択

プロジェクトフォルダ（.kicad_pro がある場所）の sym-lib-table / fp-lib-table を作成・更新します。

グローバルのライブラリテーブルは次の場所にあります。

  • Windows:
  • macOS:
  • Linux:

インポート後に、KiCad の「設定 → シンボルライブラリを管理 / フットプリントライブラリを管理」の「グローバルライブラリ」タブへ登録するライブラリ名とパスを表示します。1 つのライブラリにまとめる設定なら、登録は最初の 1 回だけで、以降は部品が同じライブラリに追記されるだけなので作業は要りません。

既存のテーブルを読み込むと、更新したファイルもダウンロードできます（任意）。

未選択

Windows の AppData や macOS の Library は Chrome / Edge の制限で選択できません。直接更新が使えるのは主に Linux です。直接更新する場合は KiCad を終了した状態で行ってください。

3ZIP をドロップ

ここに ZIP ファイルをドラッグ＆ドロップ（複数可）

または 　.kicad_sym / .kicad_mod / .step 等の単体ファイルも可

対応: Component Search Engine (SamacSys) / SnapEDA / Ultra Librarian / その他 KiCad 形式を含む ZIP
